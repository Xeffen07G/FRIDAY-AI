# Showcase Prompts & Test Cases

Use these prompts to demonstrate specific capabilities of F.R.I.D.A.Y.

## 🧠 Cognitive & Memory
- **Memory Recall**: *"What was the main topic of our first session?"* (Tests Episodic Memory)
- **Fact Retrieval**: *"Who developed you?"* (Tests Identity Layer)
- **Context Synthesis**: *"Summarize our project goals based on my notes."* (Tests Semantic Retrieval)

## 🛠️ Tool Orchestration
- **File System**: *"List all Python files in the backend folder."*
- **Research**: *"Search the documentation for 'vector persistence'."*
- **Diagnostics**: *"Run a full system health check."*

## 🎙️ Voice & Interaction
- **Interruption**: Speak over Friday while she is responding. (Tests Barge-in/VAD)
- **Whisper**: Speak very softly. (Tests Noise Suppression/Gain Control)
- **Fast-Talk**: Speak quickly without pauses. (Tests Buffer Management)

## 📊 Engineering Hub (Observability)
- **Packet Inspection**: Send a message and watch the `RECV` event in the inspector.
- **Latency Benchmarking**: Check the `Latency` tab after a complex tool call.
- **Memory Visualization**: View the `Memory` tab to see active dimensions and index types.
