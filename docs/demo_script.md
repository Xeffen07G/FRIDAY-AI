# F.R.I.D.A.Y. Showcase Script

This script is designed for a 3-minute high-impact demonstration of the F.R.I.D.A.Y. AI Operating System.

## 🎙️ Preparation
1. Ensure **Ollama** is running.
2. Launch the system using `./start_friday.ps1`.
3. Open the browser to `localhost:5173`.
4. (Optional) Enable **Demo Mode** in Settings for deterministic results.

## 🎭 The Flow

### 1. The Awakening (0:00 - 0:45)
- **Action**: Open the Landing Page. Scroll through the cinematic sections.
- **Prompt**: *"Hello, Friday."* (Voice or Text)
- **Friday**: *"Greetings, sir. All systems are operational..."*
- **Highlight**: Point out the glassmorphism and the instant response time.

### 2. Cognitive Recall (0:45 - 1:30)
- **Action**: Switch to the **Engineering Hub** tab.
- **Prompt**: *"What do you remember about our last session?"*

### 3. Real-time Orchestration (1:30 - 2:30)

- **Prompt**: *"List the files in this directory."*
- **Friday**: *"Listing the files now..."*
- **Highlight**: Point to the **Event Inspector**. Show the WebSocket packets (SEND/RECV) flowing in real-time as the tool executes.

### 4. Technical Deep Dive (2:30 - 3:00)

- **Summary**: *"F.R.I.D.A.Y. isn't just a chatbot; it's a modular OS that orchestrates local models, vector databases, and system tools with full observability."*
